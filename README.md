## Overview

Client-only, standalone. Defines the Cayo Perico polyzone and toggles island-hopper mode, the heist-island minimap, ambient audio zones, and pathnode/scenario settings on `Polyzone:Enter`/`Polyzone:Exit`, streaming the island's IPLs in and out with it.

---

## Dependencies

- `pulsar_core` — framework core
- `pulsar_polyzone` — the zone this is built on
